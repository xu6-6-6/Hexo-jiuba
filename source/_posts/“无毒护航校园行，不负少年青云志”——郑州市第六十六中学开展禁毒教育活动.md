# “无毒护航校园行，不负少年青云志”——郑州市第六十六中学开展禁毒教育活动

![](https://img-volc.jianpian.info/2322588/article/20241218/46eed96491324b53ae3c1fcb03e733efepand__jpg.heic~tplv-flrovnc8r8-s2-cC-q:0:0:0:0:q80.webp )

      为进一步加强青少年毒品预防教育，提高学生们识毒、防毒、拒毒的能力。2024年12月18日下午，秦岭路办事处偕同郑州市白庙强制隔离戒毒所警官一行走进郑州市第六十六中学开展“无毒护航校园行，不负少年青云志”为主题的禁毒宣传教育活动。

![](https://img-volc.jianpian.info/2322588/article/20241218/6d9735a2e3d8429f9f53398ebb9682e6epand__jpg.heic~tplv-flrovnc8r8-s2-cC-q:0:0:0:0:q80.webp )

    李云鹏警官用生动的案例形象的图片从吸毒危害、毒品种类、伪装性极强新型毒品以及如何预防毒品等方面进行讲解。讲解新型毒品预防时，禁毒民警严肃地告诫同学们，千万不要因为好奇而去尝试任何来路不明的东西，哪怕看似是普通的食品或小玩意。同时强调，在社交场合中，要坚决拒绝陌生人提供的任何食物和饮料，避免出入不良场所。

       最后，活动还设置了互动环节禁毒知识问答有奖以及近距离观看仿真毒品环节。

![](https://img-volc.jianpian.info/2322588/article/20241218/f0c2cab4aab1464f9dbfde0c4791a475epand__jpg.heic~tplv-flrovnc8r8-s2-cC-q:0:0:0:0:q80.webp )

     同学们纷纷表示，通过宣传教育，我们对禁毒知识和毒品危害有了更深的认识，以后生活中我们要更加小心谨慎，加强自我防范辨别意识，远离毒品危害，珍惜生命健康。

![](https://img-volc.jianpian.info/2322588/article/20241218/64d5de28323a4754a867913e2a3420d1epand__jpg.heic~tplv-flrovnc8r8-s2-cC-q:0:0:0:0:q80.webp )
