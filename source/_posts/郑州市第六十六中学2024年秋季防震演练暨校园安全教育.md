# 郑州市第六十六中学秋季防震演练暨校园安全教育

![](https://img-volc.jianpian.info/2322588/article/20240921/5ce255f3342d4d749c94b1bb43f72ba5epand__jpg.heic~tplv-flrovnc8r8-s2-cC-q:0:0:0:0:q80.webp )

     为加强师生的安全意识，强化师生的安全逃生技能，提高学校的应急处置能力，2024年9月20日郑州市第六十六中学开展防震演练活动。

  

     学校高度重视，精心组织 制定详细的演练方案。各班班主任提前利用早读时间向学生讲解地震的相关知识、应急避震的方法以及疏散的路线和安全注意事项。演练前5分钟各岗位老师提前到场，为演练的顺利进行做好了充分准备。

![](https://img-volc.jianpian.info/2322588/article/20240921/7538cd128e624225aa21a53e91c3f7e8epand__jpg.heic~tplv-flrovnc8r8-s2-cC-q:0:0:0:0:q80.webp )

       随着第一声警报声的响起，地震演练正式开始。教室里，老师们迅速反应，立即指挥学生们进行紧急避险。学生们双手抱头，迅速躲到课桌下，身体紧紧蜷缩，尽可能地保护自己的要害部位。他们神情紧张而专注，严格按照老师的指示行动。短暂的避险之后，警报再次响起，学生们在老师的带领下，按照预定的疏散路线，快速、有序地撤离到安全地带。他们用书本护住头部，弯腰低姿前行，队伍整齐而不慌乱。到达集结点各班班长清点人数，并向安全员汇报班级情况。

![](https://img-volc.jianpian.info/2322588/article/20240921/068f8985a20143fe99efc00f16f10a1fepand__jpg.heic~tplv-flrovnc8r8-s2-cC-q:0:0:0:0:q80.webp )

![](https://img-volc.jianpian.info/2322588/article/20240921/c05f3674bb33429095843fb5c58229c9epand__jpg.heic~tplv-flrovnc8r8-s2-cC-q:0:0:0:0:q80.webp )

</p>
演练结束后，崔老师进行点评，肯定了师生们在演练中的表现，同时也指出了存在的不足之处，希望大家以此次演练为契机，进一步提高防震安全意识，掌握应急避震的正确方法，确保在地震来临时能够快速、高效、有序地进行避险和疏散。

![](https://img-volc.jianpian.info/2322588/article/20240921/5b8f0cef3e844f899581c5b210ad3d10epand__jpg.heic~tplv-flrovnc8r8-s2-cC-q:0:0:0:0:q80.webp )

![](https://img-volc.jianpian.info/2322588/article/20240921/5ecc9bf9beb94f5b95ff9ecec6ccbea8epand__jpg.heic~tplv-flrovnc8r8-s2-cC-q:0:0:0:0:q80.webp )

   之后，崔老师又对开学一个月来的校园安全问题进行总结，从防坠安全、校园周边交通安全、网络安全、预防未成年人犯罪安全等方面对学生进行安全教育。

   此次防震演练活动及校园安全教育，不仅增强了全校师生应急避险能力，还加强了学校安全教育，六十六中学今后会继续为师生的生命安全和校园的和谐稳定保驾护航。
